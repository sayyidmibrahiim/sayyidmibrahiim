### 💭 What I do

I like starting with a simple question:

**"What if this could be automated?"**

Then I turn that question into a working system.

My work revolves around:

- 🤖 AI-assisted software engineering
- ⚙️ Workflow & browser automation
- 🐍 Python applications and tooling
- 🖥️ Desktop application development
- 🔌 System & application integrations
- 🐳 Docker and operational automation
- 🧠 Experimenting with better ways for humans and AI to build software together

I use AI heavily in the implementation process, while keeping architecture, constraints, verification, and engineering decisions explicit.
